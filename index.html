By the Gazette desk · Atlanta, GA

ATLANTA — Manas Jha is an AI Engineer at DevHawk AI, where he builds AI agents and LLM-powered tooling that take software work from idea to shipped code.

He holds a Bachelors in Artificial Intelligence from Purdue (2026) and has 2+ years building cloud, data-heavy systems on Google Cloud. On his own time he is founding a local-first operating system for AI agents.

“I build AI systems, then I build the tests that prove whether they actually work.”Manas Jha

He is reachable about software engineering roles, AI coding-agent tooling, model evaluation, or what he is building in stealth. Continued on the back page.

Agent harness · personal project

DUM-E

My Claude Code agent harness: six agent sessions take a card from a frozen spec through a capped build-and-repair loop to an independent verifier. A miss means a new plan instead of a blind retry, and every miss becomes a lesson.

6
agent sessions
3
tries per sub-task
2
replans, then a person
  • Claude Code
  • Multi-agent
  • Agent pipelines
  • Lifecycle hooks
  • Node.js
  • Canvas 2D
Continued: open case file
  • A coordinator freezes the spec, a builder works each sub-task with at most 3 tries, and a separate verifier checks the result against the spec.
  • A failed check goes back for a new plan; after 2 replans a person decides. Every run is written to a ledger with its model, time and token cost.
  • The desk shows it all as a 1-bit workstation: cards moving through the pipeline, handoffs travelling between sessions, and the ledger filling in.
